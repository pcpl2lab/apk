sshforward Alpine repository

Alpine packages for sshforward, an SSH port forwarding manager.

Add the repository

curl -fsSL https://apk.pcpl2lab.ovh/pcpl2lab.rsa.pub | sudo tee /etc/apk/keys/pcpl2lab.rsa.pub >/dev/null
echo "https://apk.pcpl2lab.ovh" | sudo tee -a /etc/apk/repositories
sudo apk update
sudo apk add sshforward

Later updates

sudo apk add --upgrade sshforward

Architectures: aarch64 armhf x86 x86_64. Packages and indexes are signed.
